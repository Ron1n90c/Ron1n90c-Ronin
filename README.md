# Ronin

One add-on for both worlds: tank macros for GSE, Retail and WoW: Forever.
Download: https://ron1n.cc | CurseForge: Ronin

The add-on files are in the repo root (packaged as the `Ronin` folder). Release: push a tag like `v2.0.2` and GitHub packages it and uploads to CurseForge.
Needs the repo secret `CF_API_KEY` (CurseForge API token) and the repo variable `CF_PROJECT_ID` (the project's ID number).
