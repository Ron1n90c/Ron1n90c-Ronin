RONIN - one add-on for both worlds                              V2.0.1
Tank macros for GSE (Gnome Sequencer Enhanced): Retail AND WoW: Forever in one add-on.
Website: https://ron1n.cc   |   Ko-fi: https://ko-fi.com/ron1n90c   |   Patreon: https://www.patreon.com/RON1N90C

REQUIRES: GSE.

INSTALL
 1. Install GSE, then copy the "Ronin" folder to Interface\AddOns (both games use the same folder).
 2. If you had the old "RoninInstaller" or "RoninForever" folders, delete them first (Ronin replaces both).
 3. Log in, type /ronin. On the welcome screen choose your world: Forever or Retail.
 4. Tick the classes you want and press "Import Selected". Each row shows: Up to date / Update available /
    Not installed. Keep "Overwrite" ON to update.
 5. Open GSE, bind the sequence, put the macro on your action bar. After every GSE update, place the macro
    on the bar again.

COMMANDS
 /ronin            open (welcome screen)
 /ronin retail     open the Retail installer
 /ronin forever    open the Forever installer
 /ronin debug      print what the add-on sees in GSE (send me this if a status looks wrong)

WINDOW
 Drag the bottom-right corner to resize. "Thank you" shows Ko-fi / Patreon / website links
 (click a box, Ctrl+C, paste in your browser - add-ons cannot open web pages).

RONIN RETAIL V5.2.1 (Midnight 12.0.x) - 12 sequences
 Protection Warrior (Mountain Thane, Colossus), Protection Paladin (Lightsmith, Templar),
 Guardian Druid (Elune's Chosen, Druid of the Claw), Brewmaster Monk (Master of Harmony, Shado-Pan),
 Vengeance Demon Hunter (Aldrachi Reaver, Annihilator), Blood Death Knight (Deathbringer, San'layn).
 Versions inside each: Mythic, Raid, Delve (Brewmaster also "All In").
 Modifiers: Shift = heal / self-sustain, Alt = crowd control.
 Note: the Annihilator sequence is now called RoninDH_Vengeance_Annihil (GSE cuts longer names). If you
 have the old "RoninDH_Vengeance_Annihilato", delete it in GSE and bind the new one.

RONIN FOREVER V1.7.0 (WoW: Forever) - 3 classes x 3 versions
 Protection Paladin, Protection Warrior, Feral Druid (Bear), each with Leveling 1-20, Leveling 20-40, 60.
 Modifiers: Shift = heal, Alt = CC (stun), Ctrl = interrupt.
 Plain spell names (no ranks, no IDs). Druid uses Bear Form while leveling, Dire Bear Form at 60.

RULES OF THE PACK
 Tank only. No DPS rotations, no trinkets, no big defensive cooldowns (you press those).
 Every macro step stays under GSE's 255-character limit after compiling.
